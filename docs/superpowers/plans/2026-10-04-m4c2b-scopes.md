# M4c-2b-i: scopes, declaration names and `resolveGlobalName` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A header-less source that uses `namespace`/`section`/`end`/`open`/`… in`, dotted/`_root_`/`protected` declaration names, and identifiers resolved through enclosing namespaces, `open` declarations and imported aliases elaborates per command exactly as the oracle does. Anything the oracle would resolve to two or more candidates, or to the declaration being defined, stops with a named seam.

**Architecture:**
- **Tables.** `leanr_olean` decodes three more extensions (`protectedExt`, `namespacesExt`, `aliasExtension`). `leanr_elab::names::NameTables` owns them, seeded from the `.olean` and grown by the file.
- **Scopes.** `CommandElab` gains the oracle's scope stack (`Command.Scope`: header, current namespace, open declarations). A new `command/scope.rs` ports `namespace`/`section`/`end`/`open`/`in`. Declarations go through `expandNamespacedDeclaration` and a `mkDeclName` port.
- **Resolution.** `resolve.rs` becomes the oracle's candidate-list `resolveGlobalName` plus `resolveLocalName` (including the aux-declaration matcher), parameterised by a `ResolveCtx` that `TermElabM` carries.
- **Gate.** The M4c-2a file gate grows from 18 to 89 records.

**Tech Stack:** Rust (workspace crates `leanr_olean`, `leanr_elab`; test support in `leanr_meta/tests/support`), Lean 4 `v4.33.0-rc1` as the oracle (fixture generation only), `serde_json` in tests.

**Spec:** `docs/superpowers/specs/2026-10-04-m4c2b-scopes-design.md`. Read its "The oracle model", "User decisions" and "Architecture" first. The M4c-2a spec (`2026-10-04-m4c2a-file-loop-design.md`, § Landed) defines `elab_commands` and the file gate, which this plan extends.

## Review Focus

The happy-path corpus does not reach these, and they are the most likely to bite a user. Each one has a test in the owning task.

1. **A source that ends with a `namespace` or `section` still open.** The oracle accepts it silently (`err/protectedShort`'s prefix). leanr must not invent an error at end of input. → Task 3 `an_unclosed_namespace_at_end_of_input_is_fine`.
2. **An identifier with two or more candidates.** Root plus `open` (`def shown; open Scope0; shown`), root plus alias, two `open`ed namespaces: the oracle reports `Ambiguous term`. leanr must seam `— M4c-2b-ii`, never pick one. → Task 2 `two_candidates_are_an_m4c2b_ii_seam` (unit) and Task 3 `ambiguous_identifiers_seam_end_to_end`.
3. **A body that names its own declaration inside a namespace.** `def x := Nat.zero; namespace A; def x := x` and the theorem, `example`, dotted and `A.f` variants: the oracle reports recursion. leanr must seam, never resolve the root `x`. At the same time `def foo.aux; def foo := foo.aux` must succeed. → Task 4 `recursive_references_seam_in_namespaces` and corpus `res/globalDeclFound`.
4. **Reserved and field-shadowing declaration names.** `def enumToBitVec` (reserved even when atomic), `def f.eq_1` after `def f`, `def Prod.fst`: the oracle rejects each. leanr must seam, never admit. → Task 3 `reserved_and_shadowing_names_seam`.
5. **Scope forms the oracle accepts but leanr defers.** `open scoped Scope0`, `noncomputable section`, `def f : Nat := open Scope0 in shown`: each must stop with its `later M4` seam, not a wrong `Ok` or an unrelated error. → Task 3 `deferred_scope_forms_are_named_seams`.

- **Deferred forms the oracle accepts:** `open scoped Scope0`, `noncomputable section … end`, and term-level `open Scope0 in shown`.
- **Discriminators for the mutation lists, all probed:**

  - `def g (g : Nat) : Nat := g` admits `g`: a binder shadows the aux local.
  - `def x; namespace A; def x : Eq x x := rfl` admits `A.x`: the header has no aux local, so `x` is the root `x`.

/// oracle: `ResolveName.resolveGlobalName` (`ResolveName.lean:194-216`).
/// `prefixes[k]` names the identifier's first `k + 1` components (interned
/// with `base`, Global Constraints § Name identity). Returns every
/// candidate with its number of trailing field components; empty = not
/// found. `eraseDups` keeps first occurrences.
pub fn resolve_global_name(
    st: &mut Store,
    view: &EnvView,
    rc: &ResolveCtx,
    prefixes: &[NameId],
) -> Result<Vec<(NameId, usize)>, ElabError> {
    let n = prefixes.len();
    for (k, &id) in prefixes.iter().enumerate().rev() {
        let projs = n - 1 - k;
        let mut found = resolve_using_namespace(st, view, rc, id, rc.ns)?;
        if found.is_empty() {
            if let Some(exact) = resolve_exact(st, view, id)? {
                return Ok(vec![(exact, projs)]);
            }
            if view.get(id).is_some() {
                found.push(id);
            }
            found = resolve_open_decls(st, view, rc, id, found)?;
            let mut al = rc.tables.get_aliases(id, is_atomic(st, Some(view.store), Some(id)));
            al.extend(found);
            found = al;
        }
        if !found.is_empty() {
            let mut seen = Vec::new();
            for c in found {
                if !seen.contains(&c) {
                    seen.push(c);
                }
            }
            return Ok(seen.into_iter().map(|c| (c, projs)).collect());
        }
    }
    Ok(Vec::new())
}

/// oracle: `resolveLocalName` (`ResolveName.lean:460-622`). Per prefix,
/// longest first:
/// 1. A regular local whose user name is the prefix wins
///    (`matchLocalDecl?`, the reverse scan of `findLocalDecl?`).
/// 2. Unless `skipAuxDecl`, the declaration being defined (`rc.aux_decl`,
///    installed by `withFunLocalDecls`, `MutualDef.lean:359-366`) is tried
///    with `matchAuxRecDecl?` (`:497-548`), then by exact user name
///    (`:568-572`). leanr has no aux local, so a hit is the recursion seam.
/// 3. Else, unless a global was already found, `resolveGlobalName` on
///    the prefix decides `globalDeclFound` for the next, shorter prefix.
///
/// The aux local is OUTERMOST in the oracle's context, so every regular
/// local is checked before it.
pub fn resolve_local_name(elab: &mut TermElabM, prefixes: &[NameId]) -> Result<Option<(ExprId, usize)>, ElabError> {
    let n = prefixes.len();
    let mut global_found = false;
    for (k, &given) in prefixes.iter().enumerate().rev() {
        let projs = n - 1 - k;
        if let Some(fvar) = elab.mctx.lctx_lookup_by_name(given) {
            return Ok(Some((fvar, projs)));
        }
        let skip_aux = global_found && projs > 0;
        if !skip_aux {
            if let Some(aux) = elab.resolve.aux_decl {
                if match_aux_rec_decl(elab, aux, given) || aux.short == given {
                    let base = Some(elab.view.store);
                    let shown = crate::names::render(elab.mctx.store(), base, Some(aux.short));
                    return Err(ElabError::UnsupportedSyntax(format!(
                        "recursive reference to `{shown}` — later M4 (recursion)"
                    )));
                }
            }
        }
        if !global_found && elab.resolve_global(&prefixes[..=k])?.iter().any(|&(_, f)| f == 0) {
            global_found = true;
        }
    }
    Ok(None)
}
